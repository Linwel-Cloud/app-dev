# My First README: The Walking Dead 🧟

---

### Key Reasons I Love It

* **Character Evolution:** Watching characters like Rick, Carol, and Daryl change drastically over the years.
* **Moral Dilemmas:** The show constantly asks: What are you willing to do to survive?
* **Community:** The effort to rebuild civilization against all odds (e.g., Alexandria).

### Main Protagonists

1.  Rick Grimes
2.  Daryl Dixon
3.  Michonne
4.  Negan (later seasons)
